### 🔧 Backend (3 fichiers)

#### backend/server.js (9 KB - 300 lignes)
**Rôle :** Serveur API REST
**Endpoints :**
- POST `/api/session/start` : Créer session
- POST `/api/chat` : Envoyer message
- POST `/api/report/generate` : Générer rapport
- POST `/api/report/pdf` : Télécharger PDF
- GET `/api/health` : Health check

**Lignes clés :**
- Ligne 90 : Trigger mini-diagnostic
- Ligne 98 : Appel API Claude
- Ligne 150 : Génération PDF

**Dépendances :**
- express
- @anthropic-ai/sdk
- puppeteer
- cors, dotenv, uuid

---

#### backend/prompts.js (6 KB - 150 lignes)
**Rôle :** Configuration prompts IA
**Exports :**
- `CONSULTANT_SYSTEM_PROMPT` : Comportement consultant
- `INITIAL_MESSAGE` : Message de bienvenue
- `REPORT_GENERATION_PROMPT` : Génération rapport
- `MINI_DIAGNOSTIC_TRIGGER` : Trigger diagnostic

---

#### backend/package.json (1 KB)
**Rôle :** Configuration npm
**Scripts :**
- `start` : Lancer en production
